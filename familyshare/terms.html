利用規約

施行日：2026年10月8日

第1条（適用）

本規約は、アプリ「よてい家」（以下「本アプリ」）の利用条件を定めるものです。本アプリを利用した時点で、本規約に同意したものとみなします。

第2条（データの保存についての注意）

本アプリのご利用にあたり、次の点にご留意ください。
1. 予期しない不具合により、入力したデータが失われる可能性があります
2. 機能・画面は、アプリの更新により変更されることがあります
3. 「家族と共有」を使っていない間の予定・メモは端末の中にだけ保存されます。アプリを削除すると復元できません
4. 機種変更の際に、端末の中だけにある予定・メモを引き継ぐ機能はありません
大切な予定は、他の手段でも記録しておくことをおすすめします。

第3条（有料プラン「プレミアム」）

1. 本アプリには、次の機能を利用できる有料プラン「プレミアム」があります。
・家族をつくり、招待コードで家族を招く（家族間の共有・同期）
・家族メンバーを4人目から10人まで登録する（3人までは無料です）
・大判メモ（写真の添付・季節やイベントのイラスト枠）
・なぞって入力した並びを、翌月以降まで繰り返し登録する
2. 料金は、月プラン300円（1か月ごとの自動更新）、年プラン1,800円（1年ごとの自動更新）です（いずれも税込）。実際に請求される金額は、購入時に App Store に表示される金額が優先されます。
3. 料金を支払うのは「家族をつくった人」だけです。招待されて参加した方に料金はかかりません。
4. はじめの1か月は無料です（導入オファー）。無料期間は Apple ID ごとに1回限りで、過去に本アプリの無料期間を利用された方には適用されません。無料期間中に解約した場合、残りの無料期間は失われます。

第4条（自動更新・支払い・解約）

1. 料金は、購入の確定時にお客様の Apple ID に請求されます。
2. 本プランは自動更新の購読です。期間が終了する24時間前までに解約されない限り、同じプランで自動的に更新され、更新料金は期間終了前の24時間以内に請求されます。
3. 解約は、iPhone の 設定 → お客様の名前（Apple ID） → サブスクリプション からいつでも行えます。本アプリを削除しても解約にはなりません。
4. 支払い済みの期間の途中で解約された場合でも、その期間の終了までは引き続きご利用いただけます。期間の途中解約による日割りの返金は行いません。
5. 返金は Apple の定めに従います。開発者はお客様に代わって返金を行うことができないため、返金のご希望は Apple（App Store のサポート）へお申し出ください。
6. 料金を変更する場合は、事前に本アプリ内または配布ページでお知らせします。Apple の定めにより、値上げの際は更新前にお客様の同意が必要です。
7. 未成年の方が購入する場合は、保護者の方の同意を得たうえで購入してください。

第5条（解約後の取り扱い）

プレミアムが終了した後も、すでにつながっている家族との同期は停止しません。また、それまでに作成された予定・メモは削除されず、引き続き閲覧・編集できます。
プレミアムが終了すると、次の操作ができなくなります。
1. 新しく家族をつくること
2. 新しい招待コードを発行すること
3. 4人目以降の家族メンバーを追加すること
